
# Student Grade Calculator

A beginner-friendly Python project that calculates
student marks, percentage, grades, and pass/fail results.

## Features

- Accepts student name and subject marks
- Calculates total marks and percentage
- Assigns grades automatically
- Checks pass/fail status
- Validates marks and handles invalid input

## Technologies Used

- Python 3
- VS Code

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   python grade_calculator.py

## Grading Rules

- A+: 90% and above
- A: 80% to below 90%
- B: 70% to below 80%
- C: 60% to below 70%
- D: 50% to below 60%
- E: Below 50%, if all subjects are passed
- F: Fail if any subject mark is below 35

These are example grading rules.
